# 高性價比 AI 智慧輔助眼鏡（AI_glasses）

本專案提供「高性價比 AI 智慧輔助眼鏡」的基礎開發框架，採用三層式架構設計，便於分工、快速迭代與後續量產優化。

## 專案目標

1. **語音導航**：結合定位與語音播報，提供即時路徑引導。
2. **過街輔助**：辨識斑馬線與紅綠燈狀態，提升過街安全性。
3. **跌倒通報**：透過 IMU 偵測異常動作並發送警示。
4. **尋物功能**：使用視覺辨識協助定位日常物品。
5. **即時翻譯**：語音轉文字、語意理解與語音回覆，支援跨語言溝通。

## 三層式系統架構

### 1) 硬體層（`/hardware`）
- 開發語言：C++ / Arduino
- 目標平台：ESP32-S3
- 模組：
  - `camera_stream.cpp`：影像擷取與 Wi-Fi 串流骨架
  - `imu_sensor.cpp`：IMU 數據收集與跌倒偵測骨架
  - `audio_io.cpp`：音訊輸入輸出處理骨架

### 2) 邊緣運算層（`/edge_server`）
- 開發語言：Python
- 模組：
  - `vision_yolo.py`：YOLO 介面（斑馬線 / 紅綠燈 / 物品辨識）
  - `state_machine.py`：三模式狀態機（一般導航 / 尋物模式 / 翻譯模式）
  - `speech_handler.py`：STT / TTS 處理介面

### 3) 雲端智慧層（`/cloud_services`）
- 開發語言：Python
- 模組：
  - `navigation_api.py`：Google Map API 串接（路徑規劃）
  - `llm_agent.py`：Gemini API 串接（語意理解 / 對話翻譯）

## 硬體需求清單

- ESP32-S3 開發板（含相機介面）
- 相機模組（如 OV2640）
- IMU 感測器（如 MPU6050 / ICM-20948）
- 麥克風模組（I2S / PDM）
- 喇叭與音訊放大模組
- 鋰電池與供電管理模組
- 穿戴式鏡框與基本固定結構

## 開發里程碑（五階段）

1. **硬體通訊**
   - 完成相機、IMU、音訊模組在 ESP32-S3 的驅動與資料通訊。
2. **模型訓練**
   - 建置/微調 YOLO 模型，提升場景辨識穩定性。
3. **狀態機與 API 串接**
   - 打通邊緣狀態機與 Google Map、Gemini、STT/TTS 服務。
4. **系統整合與封裝**
   - 完成跨層資料流、延遲優化、裝置封裝與功耗調校。
5. **專案收斂**
   - 進行整體測試、故障回報與使用者體驗優化，準備展示/部署。
